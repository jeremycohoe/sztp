# Cisco Catalyst 9000-series PID catalog for sZTPD device pre-registration.
#
# One row per Product ID (PID). sZTPD matches incoming devices on the PID
# token from the SUDI subject's serialNumber attribute (OID 2.5.4.5), so
# every PID you intend to onboard must appear here.
#
# Format: <PID>,<sudi_generation>
#   sudi_generation = act2     for SHA-1 / Cisco Root CA 2048 (older Cat9k)
#                   = hasudi   for SHA-256 / Cisco Root CA 2099 (C9300X, C9500X, 8000V)
#
# Lines starting with '#' and blank lines are ignored. Whitespace tolerated.
#
# Re-generate the JSON templates after editing:
#   scripts/render-device-entries.py
#
# Then recreate the containers:
#   docker compose --env-file config/catalyst/c9300.env up -d --force-recreate bootstrap redirecter
